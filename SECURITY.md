# Security

This repository automates a user-authorized local browser/control context. Do not open its local daemon or SQLite files to the internet.

Never file public bugs containing ChatGPT/Reason Network session identifiers, invite links, credentials, cookies, raw callback bodies or private project paths. Scrub logs and sample data. All provided tests are synthetic.

The Lite CLI deliberately **does not auto-repeat** operations with unknown delivery. If a callback attempt is UNKNOWN, reconcile with the original owner before sending anything else. A Reason Network send receipt is not identity proof or a Codex business ACK.

Report sensitive security findings privately to the repository maintainer.
